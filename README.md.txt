## Datasets 

Datasets are not included due to file size. Download from:

- **CICIDS2017:** https://www.unb.ca/cic/datasets/ids-2017.html
- **UNSW-NB15:** https://research.unsw.edu.au/projects/unsw-nb15-dataset

Place downloaded CSV files in a `data/` folder before running notebooks.

## How to Run

1. Clone this repository:
```bash
git clone https://github.com/alifalam/MSc-Cybersecurity-Dissertation.git
```

2. Install dependencies:
```bash
pip install -r Dependencies.txt
```

3. Download datasets, create and place in `data/` folder

4. Run notebooks in order from 01 to 08
